## brand/  — assets de marca aprovados

- `symbol/` — símbolo do Solis. Só `*-mono-transparent*` têm transparência real; os demais têm fundo escuro embutido (usar sobre fundo Night).
- `logo/` — logo horizontal e vertical.
- `states/` — estados do símbolo (listening, rings-soft, rings-strong).
- `app-icon/` — ícone de aplicativo.
