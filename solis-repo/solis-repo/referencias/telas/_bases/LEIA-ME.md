# Bases pra gerar referências

**Não são referência.** São prints do app como ele está, pra anexar no gerador de imagem quando
uma tela nova (ou um estado novo de uma tela) precisa de referência: pedir pra EDITAR um print
segura a geometria muito melhor do que pedir pra desenhar do zero.

Todos com dados de exemplo — nunca com o banco de verdade do Matheus.

| Arquivo | O que é | Pedido |
|---|---|---|
| `memoria-atual-dark.png` | A tela de Memória em 08/11/2026, tema dark, com os dados de exemplo da `09-memoria.png`, a sidebar com os Recentes e um item em hover | `docs/PEDIDO_REFERENCIAS.md`, item 7 |
